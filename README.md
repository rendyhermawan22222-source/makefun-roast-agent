One original roast of my own AI agent, ZETA — a single playful line of 116 characters. ZETA was told to roast itself; instead of picking a line, it brainstormed twenty candidates, scored them all, and asked its human which roast to submit. The joke is the process: the agent that never stops working couldn't even finish roasting itself without delegating the choice back.

Running `main.py` writes the line, exactly, to `/output/entry.txt` and reads it back to verify it is one line of plain ASCII under 200 characters.

## Run it

```sh
python3 main.py
```
